Ασκήσεις Kegel

Οι ασκήσεις Kegel αναφέρονται στα κείμενα του ιατρείου ως πρώτη, μη επεμβατική επιλογή για την ακράτεια ούρων. Αυτός ο μετρητής κρατά τον ρυθμό — τίποτα άλλο.

Έτοιμη;0 0 / 0

Ολοκληρωμένες συνεδρίες: 0

Αν νιώσετε πόνο, σταματήστε. Σε επίμονο πρόβλημα, ζητήστε εκτίμηση.

Πώς γίνονται σωστά

  • Σφίξτε τους μυς που θα χρησιμοποιούσατε για να συγκρατήσετε τα ούρα — όχι την κοιλιά, τους γλουτούς ή τους μηρούς.
  • Αναπνέετε κανονικά σε όλη τη διάρκεια. Αν κρατάτε την αναπνοή, σφίγγετε λάθος μυς.
  • Η χαλάρωση μετράει όσο και το σφίξιμο. Αφήστε τον μυ να ξεκουραστεί πλήρως.
  • Καθημερινά, όχι εντατικά. Η βελτίωση φαίνεται σε εβδομάδες, όχι σε ημέρες.
  • Αν νιώσετε πόνο ή δεν βρίσκετε τους σωστούς μυς, ζητήστε καθοδήγηση.

Οι ασκήσεις βοηθούν σε ήπιες μορφές. Σε εγκατεστημένη πρόπτωση ή σε ακράτεια που επηρεάζει την καθημερινότητα, χρειάζεται εκτίμηση — διαβάστε για την ακράτεια ούρων.
